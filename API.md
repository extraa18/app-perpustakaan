**Catatan berdasarkan pengamatan nyata:**

1. **Tipe data `tahun_terbit` tidak konsisten:** pada response GET (list maupun detail), `tahun_terbit` bertipe `string` (contoh: `"2006"`), sedangkan pada response POST dan PUT, `tahun_terbit` bertipe `number` (contoh: `2006`).
2. **Response 404 dalam mode debug Laravel:** response 404 memuat key tambahan selain `message`, yaitu: `exception`, `file`, `line`, dan `trace`. Array `trace` dipotong dengan `[...]` pada tabel di atas. Khusus baris "Hapus buku yang sudah terhapus", response ditampilkan dalam bentuk dipersingkat (hanya `message` dan `exception`).
3. **Pesan validasi PUT /api/books berbeda bahasa:** pesan error validasi pada `PUT /api/books/{id}` menggunakan bahasa Inggris (`"The judul field is required."`), sedangkan `POST /api/books` menggunakan bahasa Indonesia (`"Judul buku wajib diisi."`).
4. **Semua 10 request yang dijalankan menghasilkan status sesuai harapan.** Tidak ada status yang tidak terduga.
